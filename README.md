# MaJesticRepo-3rd

## Клонирование нужного репозитория

Клонировать

```bash
  git clone https://github.com/MaJaStudy/MaJesticRepo-3rd.git
```

Сменить папку проекта

```bash
  cd MaJesticRepo-3rd
```

Чек-аутнуть нужную ветку. Ветки созданы в формате гггг.мм.дд

```
git checkout yyyy.mm.dd
```

Сделать Pull
```bash
git pull
```
