# MaJesticRepo-3rd

## Клонирование нужного репозитория

Клонировать

```bash
  git clone https://github.com/MaJaStudy/MaJesticRepo-3rd.git
```

Сменить папку проекта

```bash
  cd MaJesticRepo-3rd
```

Чек-аутнуть нужную ветку. Ветки созданы в формате lab<b><u><i>n</i></b></u> (n - номер лабораторной)

```bash
git checkout labn
```

Сделать Pull
```bash
git pull
```
